# EzyRevenueSample

Minimal SwiftUI host app for the local `EzyRevenue` package.

- Bundle identifier: `com.whizpool.ezyrevenue.sample`
- Deployment target: iOS 15+
- No credentials are stored in the project.

Configure a development team and signing settings in Xcode before running on a device. Register the bundle identifier in the Apple Developer/App Store Connect setup before real StoreKit or Sandbox testing.
